# Why Lua?

Lua is an incredibly simple language. Both in terms of its embeddability in existing programs via its C api, and how easy it is to learn.

But due to this focus, it was unable to move on beyond these cases into broader adoption due to lack of a rich standard library (as seen with languages like Python and JavaScript), nor an easy to use package manager (as seen with Rust's Cargo, JavaScript's bun, etc).
